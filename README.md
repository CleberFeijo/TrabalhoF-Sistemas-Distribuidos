# Trabalho de Sistemas distribuidos
Projeto dedicado à criação do backend do trabalho de sistemas distribuídos

## Configurações Iniciais

---

1. Clone este projeto;
2. Copie o arquivo `.env.template` como `.env` e preecha as variáveis de ambiente (já está preenchido para facilitar sua utilização). 
3. Utilize o comando `docker-compose up -d --build` para criar as imagens do projeto (é necessário ter o docker instalado).
4. Para acessar as APIs utilize `http://localhost:8080/`.
5. Para acessar o Swagger utilize `http://localhost:8080/docs/swagger`.
